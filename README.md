# Supply Chain & Shipment Analytics

## Project Overview
An interactive Power BI dashboard designed to analyze shipment performance, sales trends, regional performance, and product sales.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX


## Dashboard Features
- **Sales KPIs:** Total Sales, Total Shipments, Total Boxes, Average Value, Total Cost, and Profit Margin
- **Monthly Sales Trend:** Track sales performance over time
- **Sales by Region:** Compare sales across regions
- **Shipment Status Distribution:** Analyze shipment statuses
- **Sales by Product:** Identify products generating the highest sales
- **Top 5 Teams by Sales:** Compare team performance
- **Key Products Overview:** Compare product sales, boxes, and average values

## Project Objective
To transform shipment data into meaningful business insights using data visualization and analysis.
